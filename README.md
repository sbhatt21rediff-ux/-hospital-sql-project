# -hospital-sql-project
PostgreSQL Hospital Database Project with SQL Queries

This project demonstrates SQL queries written in PostgreSQL
using a Hospital dataset.

## Files
- schema.sql – Table creation and data loading
- queries.sql – SQL queries for analysis
- Hospital_Data.csv – Dataset used in the project

## CSV file is stored inside the `data/` folder.


## Database
PostgreSQL

## Description
This project was created to demonstrate aggregation, grouping, and date functions.
This Hospital Data SQL Project focuses on analyzing hospital operations, patient trends, doctor availability, and medical expenses using SQL queries.

The project performs data analysis on hospital records to generate meaningful business and healthcare insights. It includes queries for calculating total patient counts, average doctors per hospital, department-wise patient distribution, and identifying hospitals with the highest medical expenses.

The project also analyzes operational metrics such as:

* Daily average medical expenses
* Longest patient hospital stay
* Average stay duration by department
* Monthly expense trends
* City-wise patient treatment analysis

Additionally, it identifies top-performing and low-performing departments based on patient count, helping in resource allocation and healthcare management decisions.

The project demonstrates practical use of:

* Aggregate functions (SUM, AVG)
* GROUP BY and ORDER BY
* Date calculations
* Filtering and sorting
* SQL reporting and analytical queries

Overall, this project showcases SQL-based healthcare data analysis skills for generating operational, financial, and patient-related insights from hospital datasets.
